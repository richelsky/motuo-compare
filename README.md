# 摩托车参数对比表（110–368cc）

30 款车、70 个配置、6 个品牌的参数横向对比，纯静态单页。

在线访问：https://richelsky.github.io/motuo-compare/compare.html

- `compare.html` 页面本体，数据、样式、脚本全部内联，零外部依赖，可离线打开
- `index.html` 根路径跳转，访问 https://richelsky.github.io/motuo-compare/ 也能进

## 怎么用

打开页面直接看，点表头排序，按品牌或排量筛。

数据以 2026 年国内在售车型的公开参数为准，价格随时会变，以当地经销商报价为准。
